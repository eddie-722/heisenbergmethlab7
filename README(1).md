# ChemForge Molecular Laboratory

A redesigned educational cheminformatics app built with Streamlit and RDKit.

## Start

1. Install Python 3.10 or newer.
2. Open a terminal in this folder.
3. Run `python -m pip install -r requirements.txt`.
4. Run `python -m streamlit run app.py`.
5. Open the local address displayed by Streamlit (typically http://localhost:8501).

Features: molecular explorer, 2D/3D models, descriptor tables, CSV/PDF exports, comparison, session collection, and quiz.

Note: session collection is temporary; this is a local web application, not an Android APK. The PDF is a concise molecular-properties report. Computational descriptors are not experimental measurements.
